# Lộ trình AI-Driven SDLC 6 tháng

Trang so sánh lộ trình hiện tại (37 tuần) với bản đề xuất 6 tháng (26 tuần).

- `index.html`: trang web, mở trực tiếp hoặc deploy GitHub Pages
- `files/AI-Driven-SDLC-6-thang.xlsx`: chương trình chi tiết và thống kê thời lượng
- `files/AI-Driven-SDLC-6-thang.docx`: tài liệu chương trình đã cập nhật

## Deploy GitHub Pages

1. Đẩy toàn bộ thư mục này lên một repository.
2. Vào Settings → Pages → Source: Deploy from a branch → chọn `main` và thư mục `/ (root)`.
3. Sau 1–2 phút, trang có tại `https://<tên-tài-khoản>.github.io/<tên-repo>/`.
